FAIR VALUE BACKTEST · 2023 → 2026적정주가 백테스트

데이터 불러오는 중…

과거 세 시점(2023·2024·2025년 11월 초)으로 돌아가 그날까지 공시된 실적과 그날 주가만으로 적정가를 다시 계산하고, 1년 뒤 실제 주가와 맞춰 봤어요. 회사별로 손으로 정한 가정·사이클 판단·뉴스는 모두 나중에 알게 된 정보가 섞여 있어서 쓰지 않고, 업종 공통 규칙만 기계적으로 적용했어요.

모델 변형 비교

학습 = 2023·2024년 기준일 8개(업종×연도) 평균, 확인 = 2025년 기준일 4개 평균. 학습 성적으로 고른 뒤 확인 기간 성적을 봤어요. 순위 상관은 0이면 무작위, 업종 대비 적중은 50%가 동전 던지기

판정별 1년 수익률

적정가 대비 30% 이상 싸면 저평가, 30% 이상 비싸면 고평가. 막대는 평균, 노란 막대는 중앙값

괴리율과 실제 수익률

가로: 기준일 적정가 대비 상승 여력, 세로: 1년 실제 수익률. 오른쪽 위·왼쪽 아래로 모일수록 모델이 맞은 것

종목별 결과

열 제목을 누르면 정렬돼요. 수익률은 배당 제외, 분할 조정 종가 기준. 결과는 '업종 중앙값보다 싸 보였는데 업종 중앙값보다 더 올랐나'로 판정

미래참조(look-ahead) 점검

막은 것

  • 실적 공시 시점: 분기 보고서는 분기말 45일, 4분기는 90일, 연간은 다음 해 3월 31일이 지나야 쓸 수 있게 했어요. 예를 들어 2025-11-05 기준이면 분기는 2025년 2분기까지, 연간은 2024년까지만 들어가요.
  • 주가: 기준일 이전 마지막 거래일 종가만 썼어요.
  • 회사별 가정: 설정 파일의 회사별 E1·성장률·사이클 위치와 리뷰 뉴스는 2026년에 쓴 것이라 전부 뺐어요. 업종 공통 기본값만 썼어요.
  • 모델 선택: 개선안은 2023·2024년 기준일 성적으로만 골랐고, 2025년 기준일은 고른 뒤 확인용으로만 봤어요. 다만 2025년 결과는 지난번에 이미 한 번 본 적이 있어서 완전히 깨끗한 확인 표본은 아니에요.
  • 제 지식: 2023~2026년 사건에 대한 제 기억은 계산에 쓰지 않았어요. 모든 숫자는 저장소 데이터와 scripts/backtest/의 스크립트에서 나와요.

남아 있는 위험

  • 종목 선정 편향(가장 큼): 대상 기업 목록은 2026년 11월 것이에요. 그사이 상장폐지·합병된 회사는 빠져 있고, 기준일이 오래될수록 이 편향이 커져요.
  • 주식수·순현금: 과거 주식수와 재무상태표가 저장돼 있지 않아 현재 주식수를 쓰고 순현금 가산은 뺐어요.
  • 업종 기본값: 성장률·할인율 기본값은 2026년에 설정 파일에 적은 값이에요. 업종 안 모든 회사에 같아서 순위에는 영향이 없지만 적정가 수준에는 영향이 있어요.
  • 표본 크기: 업종×연도 하나에 30~90개 종목이라, 모델 간 차이가 0.05 정도의 순위 상관이면 우연으로도 생길 수 있는 크기예요.
