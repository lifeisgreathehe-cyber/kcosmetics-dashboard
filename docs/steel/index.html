기사·보도자료·실적 발표에서 수치화할 수 있는 항목. 카드를 누르면 원문이 열려요.

철강 제품 가격 (생산자물가)

2020=100 · 열연·후판·냉연은 고로(포스코·현대제철), 철근·형강은 전기로(동국제강·대한제강·한국철강)의 판매가격 흐름이에요

원료 가격 (수입물가, 달러 기준)

2020=100 · 고로는 철광석·유연탄(원료탄), 전기로는 고철(철스크랩)이 원가의 60~70%예요

고로 마진 참고: 열연 가격 ÷ 원료 가격

열연 생산자물가 ÷ (철광석 1.6 : 유연탄 0.8 가중 수입물가) × 100. 쇳물 1톤에 철광석 약 1.6톤·원료탄 약 0.8톤이 들어가요. 서로 다른 통계표(생산자물가·수입물가, 원화·달러)를 나눈 값이라 절대 수준보다 방향만 참고하세요

전기로 마진 참고: 철근 가격 ÷ 고철 가격

일반철근 생산자물가 ÷ 고철 수입물가 × 100. 철근-고철 스프레드(롤마진)가 전기로 회사 이익을 결정해요. 서로 다른 통계표를 나눈 값이라 방향만 참고하세요

비철금속 가격 (생산자물가)

2020=100 · 동·아연·연(납)·알루미늄 1차 정련품과 금·은괴. 고려아연·영풍·풍산·LS의 매출이 이 가격에 연동돼요

국가별 철강재 수출

최근 24개월, 단위: 억 달러 · HS 72 · 미국 관세(50%)와 EU 쿼터 축소 이후 수출처 변화를 봐요

철강재 수입: 중국산 저가재 압박

월별, 단위: 억 달러 · HS 72 수입액과 열연·후판(HS 7208) 수입. 2025년 반덤핑 관세 이후 흐름을 봐요

출하 − 재고 순환 (1차 철강)

출하지수 증감률에서 재고지수 증감률을 뺀 값(%p, 전년 동월 대비). 플러스면 재고가 줄며 업황이 좋아지는 국면이에요.

철강 · 비철 품목별 가격 연평균 (2020=100)

한국은행 생산자물가 · 색이 진할수록 2020년보다 비싸요. 2021~2022년 철강 슈퍼사이클 뒤 판재는 중국 과잉 공급으로 내려왔고, 동·금·은은 2025~2026년 사상 최고권이에요

고로(일관제철), 전기로·봉형강, 특수강·합금철, 판재 가공(냉연·도금·컬러·스테인리스), 강관·주철관, 선재·와이어, 철강 유통·피팅, 단조·내화물·원료, 비철 제련(아연·동), 동·알루미늄 가공, 전선, 철강 무역·IT 상장사의 실적이에요. 표에서 회사를 누르면 아래에 최근 4개 분기 리뷰, 내재가치 리포트, 10년 연간 추세와 최근 12개 분기 실적이 나타나요.

    자동 갱신 구조

    이 페이지는 GitHub 저장소 kcosmetics-dashboard의 docs/steel/data 폴더에 있는 JSON 파일을 읽어 그려요. GitHub Actions가 매주 월요일과 매월 16일 오전 9시에 통계를, 하루 6번 회사별 뉴스를, 평일 장중 10분마다 주가를 갱신해요.

    • DART OpenAPI (DART_API_KEY): 상장사 10년 연간 · 분기 손익, 지배주주순이익 (해외 IP 차단으로 국내 PC에서 실행)
    • KOSIS OpenAPI (KOSIS_API_KEY): 철강·비철 생산자물가(열연·후판·냉연·철근·형강·동·아연·알루미늄·금·은, 한국은행), 철광석·유연탄·고철·동광석 수입물가, 1차 철강·비철금속 생산·출하·재고지수(국가데이터처)
    • 관세청 수출입실적 (DATA_GO_KR_KEY): HS 72·73·74·76·79 수출입, 철광석·석탄·철스크랩 수입, 국가별 철강재 수출
    • 네이버 금융: 실시간 시세, 월봉 주가, 회사별 뉴스
