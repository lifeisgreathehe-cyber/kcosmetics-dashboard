운송 물량 증감률

전년 동월 대비 %, 서비스업생산 불변지수(물량) · 외항 해운·항공 화물·소화물(택배)

택배: 물량은 늘고 단가는 제자리

소화물 전문 운송업 물량지수(막대)와 택배 생산자물가(선), 2020=100

항공 여객: 물량과 운임

항공 여객 운송업 물량지수(막대, 2020=100)와 국제항공여객 생산자물가(선)

해운 실효 운임 (매출 ÷ 물량)

외항 운송업 경상지수 ÷ 불변지수 × 100. 국적 선사가 실제로 받는 평균 운임 수준의 흐름이에요

운송 품목별 운임 연평균 (2020=100)

한국은행 생산자물가 · 색이 진할수록 2020년보다 비싸요. 해운·항공 화물은 2021~2022년 정점 뒤 급락했다가 2026년 다시 올랐고, 하역·택배·도로화물은 꾸준히 오르는 '구조형' 가격이에요

해운(컨테이너·벌크·탱커·가스선), 항공(대형·저비용 항공사, 지상조업), 택배·종합물류, 항만·하역·포워딩, 육운·물류설비 상장사의 실적이에요. 표에서 회사를 누르면 아래에 최근 4개 분기 리뷰, 내재가치 리포트, 10년 연간 추세와 최근 12개 분기 실적이 나타나요.

최근 실적을 바탕으로 회사별 정상화 이익과 성장 시나리오를 세워 주주가치를 추정했어요. 현재 시가총액이 어떤 성장률을 전제하고 있는지(역DCF)도 함께 보여줘요. 회사를 누르면 상세 리포트로 이동해요.

현재 주가 대비 적정가 범위

막대는 비관~낙관 시나리오 적정가를 현재 주가 대비 %로 나타낸 범위, 점은 기준 시나리오예요. 0% 선 위에 있으면 현재 주가가 기준 적정가보다 낮다는 뜻이에요.

    자동 갱신 구조

    이 페이지는 GitHub 저장소 kcosmetics-dashboard의 docs/logistics/data 폴더에 있는 JSON 파일을 읽어 그려요. GitHub Actions가 매주 월요일과 매월 16일 오전 9시에 통계를, 하루 6번 회사별 뉴스를, 평일 장중 10분마다 주가를 갱신해요.

    • DART OpenAPI (DART_API_KEY): 상장사 10년 연간 · 분기 손익, 지배주주순이익 (해외 IP 차단으로 국내 PC에서 실행)
    • KOSIS OpenAPI (KOSIS_API_KEY): 운송서비스 생산자물가(외항화물·항공화물·국제항공여객·택배·도로화물·항만하역 등, 한국은행), 운수업 서비스업생산지수 경상·불변(외항·내항·항공 여객·항공 화물·도로화물·소화물·버스, 국가데이터처)
    • 네이버 금융: 실시간 시세, 월봉 주가, 회사별 뉴스

    키가 등록되지 않은 소스는 마지막으로 수집된 값을 그대로 보여줘요.
