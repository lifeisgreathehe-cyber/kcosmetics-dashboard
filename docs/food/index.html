    이 페이지는 GitHub 저장소 kcosmetics-dashboard의 docs/food/data 폴더에 있는 JSON 파일을 읽어 그려요. GitHub Actions가 매주 월요일과 매월 16일 오전 9시에 아래 API에서 최신 데이터를 받아 파일을 갱신해요.

    • DART OpenAPI (DART_API_KEY): 상장사 10년 연간 · 분기 손익, 지배주주순이익
    • KOSIS OpenAPI (KOSIS_API_KEY): 식료품·음료 제조업 생산·출하·재고지수(광업제조업동향조사), 가공식품·외식 소비자물가, 밀·옥수수·콩·원당·커피·식용유·육류·우유 수입물가지수, 음식료품 수출물가지수(한국은행)
    • 공공데이터포털 관세청 API (DATA_GO_KR_KEY): 라면·과자·소스·김·음료·주류·아이스크림·커피조제품·인삼 월별 수출, 국가별 라면 수출, 밀·옥수수·대두·원당·돼지·쇠고기 수입액과 중량(단가 계산)
    • 네이버 금융: 회사별 최근 뉴스(하루 6번), 실시간 주가(평일 장중 10분 간격), 월봉 주가 이력
