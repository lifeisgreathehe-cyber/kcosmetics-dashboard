국적별 연간 방한객

단위: 만 명 · 올해는 집계된 달까지의 누적이고, 괄호는 전년 같은 기간 대비 증감률이에요 · 색이 진할수록 많이 늘었어요(파랑은 감소)

해외로 나가는 한국인 vs 한국에 오는 외국인

해외여행 목적지: 국제선 지역별 출발 여객

출국카드가 있던 시절(2003~2006)의 실제 행선지 통계

여행수지: 외국인이 쓴 돈 vs 한국인이 해외에서 쓴 돈

한국은행 국제수지 · 최근 12개월 합계, 억 달러 · 여행지급이 수입보다 크면 적자

환율: 엔·달러·위안

월말 기준 · 엔화가 싸면(원/100엔 하락) 일본 여행이 늘고, 원화가 약하면 방한객이 늘고 해외여행 경비가 비싸져요

항공사별 국제선 여객

여행 업종 매출 지수

면세점: 손님 1명이 쓰는 돈

면세점 매출 지수(12개월 평균) ÷ 방한객(12개월 합), 2019년 = 100 · 다이궁(중국 보따리상) 의존이 줄면서 손님은 늘어도 1인당 매출은 줄었어요

국제유가 (항공 연료비·유류할증료의 출발점)

브렌트유 월말 가격, 달러/배럴 · 항공사 비용의 25~35%가 연료비이고, 국제선 유류할증료는 1~2개월 전 싱가포르 항공유 평균으로 매겨져요

방한 목적: 관광·사업·유학

외래객 입국 목적 구성(2022년~), 만 명 · 관광 비중이 높을수록 면세점·카지노·여행사 인바운드에 직접 도움이 돼요

숫자로 보는 최근 동향

실적 발표·업계 통계·기사에서 수치화할 수 있는 항목. 카드를 누르면 원문이 열려요.

여행사(패키지·FIT), 항공(대형·저비용 항공사, 지상조업, 지주사), 면세점, 택스리펀드, 카지노(내국인·외국인 전용), 호텔·리조트 상장사의 실적이에요. 표에서 회사를 누르면 아래에 최근 4개 분기 리뷰, 내재가치 리포트, 10년 연간 추세와 최근 12개 분기 실적이 나타나요.

현재 주가 대비 적정가 범위

    자동 갱신 구조

    이 페이지는 GitHub 저장소 kcosmetics-dashboard의 docs/travel/data 폴더에 있는 JSON 파일을 읽어 그려요. GitHub Actions가 매일 오전 10시 30분에 통계(KOSIS)와 환율·유가를, 하루 6번 회사별 뉴스를, 평일 장중 10분마다 주가를 갱신해요.

    • DART OpenAPI (DART_API_KEY): 상장사 10년 연간 · 분기 손익, 지배주주순이익 (해외 IP 차단으로 국내 PC에서 실행)
    • KOSIS OpenAPI (KOSIS_API_KEY): 한국관광공사 방한 외래객 국적별·목적별 입국(2003~2021 구 통계표, 2022~ 신 통계표), 내국인 출국(출국항별), 내국인 행선지별 출국(2003~2006), 한국공항공사·국토교통부 항공통계 국제선 지역별·항공사별 여객, 한국은행 국제수지 여행수지, 국가데이터처 서비스업생산지수(면세점·여행사업·숙박·사행시설·항공여객·테마파크)
    • Yahoo Finance: 원/달러·원/100엔·원/위안·원/대만달러 환율, 브렌트유 월봉
    • 네이버 금융: 실시간 시세, 월봉 주가, 회사별 뉴스

    키가 등록되지 않은 소스는 마지막으로 수집된 값을 그대로 보여줘요.
